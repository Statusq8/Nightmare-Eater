# Инструкции для Codex
Проект: авторская хоррор-манхва «Пожиратель кошмаров», адаптация для YouTube.
Перед работой прочитай README.md, lore/story-bible.md, lore/character-design.md, TASKS.md и PROGRESS.md. Главы и утверждённый визуальный канон не изменяй без согласования. Черновики лора не считай окончательными. Не выдумывай отсутствующие исходники: глава 2 пока представлена конспектом, PNG героя ещё не загружен.
Работай только в Nightmare-Eater. Не публикуй видео, не покупай услуги, не передавай секреты и не меняй видимость репозитория без явного разрешения. Не добавляй ключи API в git.
Выполняй задачи из TASKS.md, проверяй результаты, отмечай статус и записывай изменения, команды проверки и блокеры в PROGRESS.md. Новые инструменты должны поддерживать Windows и локальный запуск; по возможности бесплатные. Не перезаписывай пользовательские ассеты. Не выдавай черновой текст за утверждённый.

## Память проекта
Перед новой задачей прочитай [PROJECT_MEMORY.md в main](https://github.com/Statusq8/Nightmare-Eater/blob/main/PROJECT_MEMORY.md). После содержательного обсуждения или завершённого этапа обнови этот файл в `main`: зафиксируй решения, результаты проверки, блокеры и следующий шаг. Технические подробности по-прежнему записывай в `PROGRESS.md` соответствующей ветки.
