# context-saver
1. Прочитай AGENTS.md и CURRENT_STATE.md, если ещё не загружены.
2. Определи результат, точный исходник и необходимые разделы правил/референсы.
3. Ищи по ID, заголовку или пути; читай только нужный диапазон. Не загружай историю, бинарные файлы или все Skills без причины.
4. Повторно используй уже прочитанное; при изменении версии перечитай только изменённое.
5. Если данных не хватает для канона или качества, расширь контекст адресно либо сообщи блокер. Не угадывай.
6. Не создавай дополнительные отчёты или агентов ради экономии.
