# project-memory
1. Обновляй CURRENT_STATE.md только при изменении состояния; до 50 строк.
2. Сохрани цель, решение владельца, статус, пути и версии эталонов, блокеры и один следующий шаг.
3. Не удаляй исторические PROJECT_MEMORY.md и PROGRESS.md; существенные решения и проверки добавляй кратко, не дублируй историю.
4. Проверяй сохранение повторным чтением или хешем. Не объявляй непроверенное выполненным.
5. Не записывай секреты; не меняй канон или другие репозитории.
