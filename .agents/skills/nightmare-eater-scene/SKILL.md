# Nightmare Eater scene production

1. Read PROJECT_MEMORY.md from the repository's main branch, the assigned chapter, and the relevant character and location canon. Identify the exact chapter span and distinguish established details from staging choices.
2. Build a beat sheet. For each beat, describe the start and end state, visible action, camera axis, light source, diegetic sound, and dialogue. Give the viewer time to register what changes. In chapter 001, the System windows and the door notice come from the chapter text. Set their type as editable text and check legibility at playback size. Give the System its own voice. Preserve the order of events in the selected span.
3. Reuse a scene and cameras for recurring locations. In Blender, separate moving props from the set when they must react physically. In image-to-video tests, compare the first, middle, and last frames for character and location drift. Use parallax only where it passes an edge and occlusion review; prefer motion motivated by the scene.
4. Time dialogue to the action and pauses. Respect distinct speaker identities, including the System. Review diction and acting separately. Mix dialogue, ambience, effects, and score as separate stems where possible. Check hard transients and leave deliberate silence. Register outside assets with source URL, author, license, and use.
5. Render a short proof when experimenting with a new technique, then inspect the frame before, during and after each effect. Verify playback exports by decoding the whole file and checking resolution, duration, frame count and expected audio tracks. When RU/EN are in scope, check both tracks against the same picture and keep language-specific text editable.
6. Save versioned outputs and update PROJECT_MEMORY.md with the reviewed result, remaining limitations and the next step. Use PROGRESS.md for detailed implementation or verification. Preserve previous approved cuts and user assets.
