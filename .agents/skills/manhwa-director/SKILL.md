# manhwa-director
1. Прочитай точный фрагмент и соседний контекст при необходимости; правила §03–07,09,17,21,25.
2. Составь компактный список панелей: ID, границы текста, действие, ракурс, композиция, точные реплики, референсы.
3. Варьируй масштаб, паузы и негативное пространство. Не превращай страницу в ряд иллюстраций с карточками текста.
4. Сохраняй порядок раскрытия событий, не показывай скрытое раньше времени. Не меняй канон.
5. Передай художнику только план и необходимые эталоны; один образец до серии.
