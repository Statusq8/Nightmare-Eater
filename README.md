# Пожиратель кошмаров

Авторская манхва: системный психологический хоррор, сверхъестественное выживание, RPG-прокачка.

Главный герой — Кан Джинхёк. Кошмарные инстансы, уникальные правила аномалий, поглощение сущностей и постепенная утрата человечности.

Цель: литературные главы и их адаптация в видеоманхву для YouTube.

## Принципы
Система может лгать. Сила не отменяет правила кошмаров. Поглощение передаёт способности, воспоминания и инстинкты. Главная загадка: почему Хирург уже убивал героя?
