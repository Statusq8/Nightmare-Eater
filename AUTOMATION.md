# T003 — Автоматизированная студия
Статус: READY. Приоритет перед T002.
Пользователь хочет минимального участия, без согласования каждого кадра. Сохранять утверждённый канон, принимать обратимые художественные решения самостоятельно, фиксировать их. Не изменять исходные главы и не публиковать без разрешения.
Создать единый локальный оркестратор Windows (CLI и простой интерфейс при возможности) с этапами: чтение главы и лора → сценарий/раскадровка → генерация изображений с референсами → TTS с постоянными голосами → субтитры → существующий FFmpeg монтаж → автоматические проверки → MP4, обложка, метаданные YouTube.
Провайдеры текста, изображений и TTS — сменные адаптеры; проверить актуальную документацию, не предполагать что подписки ChatGPT/Codex дают API-кредиты. Ключи только в локальном .env, пример без секретов. Предложить локальные варианты с учётом доступной VRAM, не скачивать большие модели без разрешения. Не расходовать деньги без установленного пользователем лимита; по умолчанию dry-run и нулевой платный бюджет. Оценка стоимости до запуска.
Сохранять промежуточные результаты, хеши, манифесты, журнал, повторять только неудачные этапы; возобновление после сбоя. Ограничить повторы. Проверять непрерывность персонажей, соответствие главе, наличие кадров, звук, субтитры и декодирование. Отсутствующий PNG героя явно отметить; не выдавать замену за утверждённый эталон. Сначала бесплатный синтетический end-to-end тест, затем короткий реальный пилот после настройки провайдеров и получения референса. Не публиковать автоматически.
Критерий: одна команда запуска главы, dry-run, возобновление, отчёт и готовый тестовый MP4. В PROGRESS.md записать проверенные возможности и оставшиеся блокеры.
