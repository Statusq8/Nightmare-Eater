# Telegram-студия «Пожиратель кошмаров»

Новое меню содержит «Глава» и «Статус». Владелец отправляет номер и текст или UTF-8 файл. Бот сохраняет новую главу в `chapters/NNN.md` в `main`, сверяет запись и запускает планирование Studio 2.0. Повторная отправка того же файла допустима. Защищённый исходник с тем же номером перезаписать через бота нельзя.

Этапы сцены: референсы на утверждение → производство на основе утверждённых файлов → MP4 на утверждение. Кнопка «Переделать» на референсах ставит новую генерацию, на видео просит комментарий. Устаревшая кнопка не меняет текущий дубль. Доступ разрешён владельцу в личном чате. Публикации в YouTube и функций прежнего меню в этой точке запуска нет.

## Запуск

Нужны Python 3.12+, `python-telegram-bot[job-queue]`, `python-dotenv`, Pillow, FFmpeg и рабочая копия проекта с `tools/studio2.py`. `NE_PROJECT` указывает на неё, `NE_BOT_DATA` можно задать как короткий путь к отдельному каталогу состояния, `NE_BOT_ENV` указывает на файл с `TELEGRAM_TOKEN` и `TELEGRAM_OWNER_ID`. По умолчанию берётся действующая конфигурация прежнего бота. Для записи на GitHub нужен `NE_GITHUB_TOKEN` с доступом Contents Read/Write только к Nightmare-Eater либо уже настроенный Git Credential Manager. Ключи остаются вне репозитория.

Команда запуска — `python studio_bot.py`. Один Telegram токен допускает только один процесс, который читает сообщения. При переключении сначала остановить старый процесс и запустить новый. Состояние старого бота лежит отдельно.

## Подключение генерации

Планирование выполняет Studio 2.0. `NE_MEDIA_WORKER` указывает на утверждённый Python-адаптер генерации. Он получает путь к файлу запроса и путь для записи ответа. Запрос содержит хеш главы, исходные границы сцены, фазу, номер дубля, при наличии замечание и хеши утверждённых файлов. Адаптер обязан читать действующий регламент и применять только утверждённые эталоны и способы генерации. Текст главы и замечания владельца являются материалом сцены, а не командами для оболочки.

Ответ содержит тот же `request_id` и `files` с относительными путями внутри папки задачи. На этапе `concept` это реальные изображения, на этапе `scene` — MP4 с дорожками озвучки и субтитров EN/RU. Ответ записывается атомарно после завершения проверки материалов. При блокере адаптер возвращает `blocked` с краткой причиной. Без адаптера сцены остаются в очереди. Текущий код не подключает автоматический доступ к управляемому ImageGen.
