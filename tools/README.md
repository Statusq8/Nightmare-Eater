# Локальный монтаж видеоманхвы

На Windows нужны Python 3.10+ и FFmpeg с фильтром `subtitles` (libass), кодеками `libx264` и AAC. Команды `python`, `ffmpeg` и `ffprobe` должны быть доступны в PATH. Платные сервисы и ключи API не нужны.

Из корня репозитория выполните в PowerShell:

```powershell
python tools/smoke_test.py output/smoke.mp4
```

Тест синтезирует два изображения, два звуковых сигнала и кириллические субтитры во временной папке. Он проверяет разрешение, частоту кадров, дорожки, длительность, изменение картинки внутри планов и декодирование MP4.

Для главы скопируйте `youtube/storyboards/chapter.template.json` в `youtube/storyboards/001.json` и заполните поля:

- Храните канон персонажей, фоны, планы и обложки в соответствующих папках `assets/`. Сценарий видео помещайте в `youtube/scripts/`.
- Укажите дорожку озвучки и UTF-8 SRT с таймкодами относительно начала ролика. Локальные записи находятся в `youtube/voiceover/`.
- Для каждого плана задайте уникальный ID, описание, персонажей, реплику или текст диктора, длительность в секундах, движение камеры, путь к изображению и необязательный путь к звуковому эффекту. Пути считаются от каталога JSON. Допустимые движения: `static`, `push`, `pull`, `pan`.
- Реплика и описание служат для подготовки исходников. Скрипт использует готовую озвучку и SRT. Каждый эффект начинается вместе со своим планом и обрезается до его длительности. Озвучка при необходимости дополняется тишиной или обрезается по общей длине планов. Перед экспортом сверяйте таймкоды озвучки и субтитров с раскадровкой.

```powershell
python tools/render.py youtube/storyboards/001.json output/001.mp4
```

Результат — MP4 1920×1080, 30 кадров/с, H.264/AAC. Кадры заполняют экран с центрированным кадрированием. Подготовьте композицию 16:9, если важны края иллюстрации. Готовые ролики остаются локально в `output/`.
